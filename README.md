# 🍔 FoodCaloriesFinder

FoodCaloriesFinder is a Machine Learning based web application that detects food items from images and estimates their calorie values using image classification techniques and Computer Vision.
This project helps users identify food items and understand approximate calorie intake by uploading food images. The system uses Machine Learning models trained on food datasets to recognize food categories and provide calorie information instantly.

# 📌 Project Overview

Maintaining a healthy diet and tracking calorie intake is important for fitness and health management. Calculating calories manually for every meal can be difficult and time-consuming.

FoodCaloriesFinder solves this problem using Machine Learning by:
- Detecting food items from uploaded images
- Predicting food categories
- Estimating calorie values
- Providing quick and easy results

This project is useful for:
- Fitness enthusiasts
- Diet tracking
- Health monitoring
- Students learning Machine Learning
- Computer Vision projects

# 📖 File Description

### `app.py`
Main Flask application used to run the web interface.

### `calories.py`
Contains calorie-related logic and mappings for food items.

### `check_data.py`
Used for checking dataset quality and validating image data.

### `train_model.py`
Main Machine Learning model training script.

### `train_model_v2.py`
Improved or alternative training version.

### `train_small_data.py`
Used for training with smaller datasets for testing purposes.

### `test_model.py`
Tests the trained ML model on sample images.

### `requirements.txt`
Contains all required Python libraries.


# 📸 How the System Works
 Step 1 : User uploads a food image.
 Step 2 : Image preprocessing is performed using OpenCV.
 Step 3 : The trained ML model analyzes the image.
 Step 4 : Food category is predicted.
 Step 5 : Estimated calorie value is displayed.
